# SVN 证书名称不匹配排查

典型错误为 `E230001`，附带 `certificate issued for a different hostname`。这属于 TLS 证书名称校验失败，应先核对访问地址与证书名称；该错误本身不能证明账号或密码有误。

## 客户端行为

程序使用非交互 SVN 请求、独立 SVN 配置目录，并禁止额外缓存认证密码。默认不跳过服务器证书验证；浏览器或另一个 SVN 客户端保存的证书例外不一定在本工具中生效。

仓库编辑窗口仅验证 URL 格式，不会在保存时连接服务器或自动信任证书。

## 处理顺序

1. 确认仓库管理员提供的正式域名，例如 `https://svn.example.invalid/docs`，保持正确的仓库路径。
2. 核对 DNS 解析和服务器证书是否覆盖该域名。
3. 若必须使用 IP 地址，优先由管理员提供覆盖该 IP 的证书；也可按需使用单仓库名称兼容选项。
4. 若名称问题解决后出现证书过期、签发机构不受信任或认证错误，再分别处理对应原因。

不要默认关闭全部证书验证，也不要为排查名称问题改用未加密传输。
