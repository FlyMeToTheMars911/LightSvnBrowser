# 故障排查

本文中的域名、目录和用户标识均为占位示例。请在自己的环境中替换；不要把密码写进仓库 URL、命令行或公开问题反馈中。

## HTTPS 证书名称不匹配

典型错误：

```text
svn: E230001: Server SSL certificate verification failed:
certificate issued for a different hostname
```

这表示访问地址的主机名与服务器证书中的名称不一致。例如，服务器证书覆盖域名，而连接使用 IP 地址。浏览器显示“不安全”但仍可查看，并不代表证书验证已经通过；浏览器保存的例外也不一定与 SVN 客户端共享。

优先使用证书覆盖且能够解析的仓库域名，例如 `https://svn.example.invalid/docs`，并保持原仓库路径。若必须通过 IP 访问，建议由服务器管理员提供覆盖该 IP 的有效证书。

需要兼容现有 HTTPS IP 地址时，可编辑该仓库，手动勾选“允许 IP 地址与证书域名不一致（仅此仓库）”。程序仅放行该仓库的证书名称不匹配，继续验证有效期、签发机构等其他问题；默认不启用。URL 改成域名或其他协议后，复选框自动取消并禁用。详见 [HTTPS IP 地址兼容说明](20261102-IP仓库兼容与真实访问验证.md)。

## 认证失败或权限不足

请求失败后程序停止，不会自动重试或后台轮询。请先确认仓库地址、用户名和访问权限，再手动发起一次操作。证书错误与账号密码错误应分别处理，不要通过反复修改密码排查证书名称问题。

密码使用当前 Windows 账户的 DPAPI 加密。将数据目录复制到另一台机器或另一个 Windows 账户后，可能需要在仓库设置中重新输入密码。

## 搜索不到新增文件

普通搜索查询本地文件名索引。SVN 中新增、移动或修改文件后，点击“更新搜索索引”；搜索范围可选择当前仓库、所有仓库或当前目录及子目录。

文件名搜索不检索正文。收藏页另支持按收藏名称、标签、备注和路径查找。

## 收藏失效或文件大小不一致

收藏保存路径入口。打开时程序重新读取最新文件元数据；文件移动、重命名、删除或类型变化后，原入口可能失效。重新定位文件并更新收藏。

从旧搜索索引读取文件时，如果服务器上的文件已变化，请更新索引后再操作，不必重新下载整个仓库。

## 无法打开 Office 或 PDF

程序使用本机默认阅读软件打开只读临时副本。确认系统中已安装对应软件并设置文件关联，也可使用“下载到…”保存后自行打开。应用不捆绑 Office 转换或编辑引擎。

## 数据目录不可写

默认数据目录为 EXE 旁的 `data` 子目录。可在设置中更换目录，或使用 `LightSvnBrowser.exe --data-dir "<数据目录>"`。程序不会在目录不可写时自动改用其他位置。

更换目录后，请使用新目录内生成的专用启动快捷方式。直接双击原 EXE 仍遵循默认目录规则。原目录保留；缓存和索引不会自动迁移。

## 提供问题反馈

可附上操作步骤、程序版本、错误文本，以及 `logs` 下与该次操作对应的日志片段。分享前请移除实际仓库地址、用户名、内部目录、证书标识及其他组织信息；不要附上 `settings.json`、密码、整个数据目录或未经检查的截图。
