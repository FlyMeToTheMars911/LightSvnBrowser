# HTTPS IP 地址兼容说明

适用于 0.1.1 起的按仓库证书名称兼容选项。

## 功能

仓库设置提供“允许 IP 地址与证书域名不一致（仅此仓库）”。该选项默认关闭，仅在仓库地址是 HTTPS 的 IPv4 或 IPv6 地址时可用；改为域名或非 HTTPS 协议时自动取消并禁用。

保存设置只更新本地配置，不连接服务器。启用后，该仓库的 SVN 请求才会增加 `--trust-server-cert-failures cn-mismatch`；其他仓库维持默认验证。

该选项只兼容证书名称不匹配，仍验证证书有效期和签发机构等其他问题。它不会修改系统信任存储、浏览器设置或其他 SVN 客户端的全局配置。建议优先使用证书覆盖的正式域名。

## 使用

1. 与仓库管理员确认正确的 HTTPS 仓库地址及证书归属。
2. 优先填写证书覆盖且能够解析的域名，例如 `https://svn.example.invalid/docs`。
3. 若环境必须通过 IP 访问，在该仓库的编辑窗口勾选兼容选项并保存。
4. 手动选择仓库访问一次。失败后先检查错误类型，程序不会自动重试。

## 验证方法

运行 `scripts/Verify.ps1`。自动化测试使用本地仓库、离线模拟 SVN 响应和离屏 WinForms 控件，不连接用户的远程仓库。

相关测试覆盖：

- 新仓库默认关闭、已有仓库编辑保留、配置序列化兼容。
- HTTPS IPv4/IPv6 地址可选；域名与其他协议不能启用。
- URL 变更后清除选项，其他仓库不受影响。
- SVN 参数仅放行 `cn-mismatch`，不设置其他证书忽略项。

具体测试结果以本次验证输出为准，不代表所有服务器、证书链或认证方式均已验证。连接排查见 [故障排查](TROUBLESHOOTING.md)。
