# 初版功能与验证范围

## 运行与交付

应用为 Windows x64 单 EXE，使用 .NET Framework 4.8 / Windows Forms。正式构建内置压缩的 SVN 命令行客户端，运行时解压到选定数据目录；不需要安装 Node、Java、数据库或独立浏览器内核。

默认数据目录是 EXE 旁的 `data`。可以使用启动参数、环境变量或设置页生成的专用快捷方式选择其他目录。数据目录统一保存仓库配置、加密密码、收藏、文件名索引、缓存、日志、隔离 SVN 配置、运行时和程序临时文件。

## 功能对应

| 功能 | 实现 |
| --- | --- |
| 多仓库及分组 | 新增、编辑、移除仓库，多级分组路径 |
| 收藏 | 文件或目录入口、可编辑名称、标签、备注和筛选 |
| 文件名搜索 | 多关键词，当前仓库、所有仓库或当前目录及子目录 |
| 按需查看 | 文本与图片内嵌预览，其他支持类型交给本机默认阅读软件 |
| 主动下载 | 自行选择保存位置，不修改 SVN 中的文件 |
| 轻量存储 | 本地 JSON 配置与元数据索引，不 checkout 整个仓库 |
| 密码保护 | 当前 Windows 账户 DPAPI 加密，标准输入传递凭据，不额外缓存认证密码 |

## 构建与验证

```powershell
.\scripts\Build.ps1
.\scripts\Verify.ps1
```

自动化验证包含：

- 配置加密与序列化、损坏配置保护、URL 和特殊文件名。
- 本地 SVN 仓库目录读取、固定版本索引、文本与二进制获取。
- 缓存只读属性、容量与过期清理、原子下载。
- 超时、主动取消、错误脱敏、认证失败不重试及安全 XML 解析。
- 真实 WinForms 控件离屏保存、嵌套分组、收藏别名与原文件后缀、最新收藏元数据、标签备注搜索、目录搜索边界和导航竞态。
- 自定义数据目录快捷方式、客户端运行时释放与主窗口渲染。

测试使用本地测试仓库和离线模拟响应，不连接用户配置的远程仓库。测试产物和日志保存在 `work`，不写入正式 `data`。具体断言数量、结果和产物以本次脚本输出为准。

## 使用边界

文件名索引不检索正文，更新由用户手动触发。收藏入口无法自动跟踪文件移动和重命名。Office/PDF 由本机默认程序打开，Markdown 按纯文本展示。

临时查看单文件上限为 64 MiB，且不超过配置的缓存上限；内嵌文本显示前 2 MiB。默认缓存上限 256 MiB，保留 7 天。大文件可主动下载；外部阅读软件锁定的缓存文件可能暂时无法清理。

本工具不修改 SVN 文件，不提供在线编辑提交、仓库权限管理或内置 Office 转换引擎。增强 SASL/Kerberos 的可移植性边界见根目录 [第三方说明](../THIRD-PARTY-NOTICES.md)。

Windows 和外部阅读软件自行管理其缓存与历史记录；工具只能约束自身及 SVN 子进程的文件位置。数据目录切换后应使用专用启动快捷方式，原目录保留。

连接与证书问题见 [故障排查](TROUBLESHOOTING.md)。
