# 版本记录

## 0.2.1 — 2026-11-02

设置页新增界面字号，支持 8–16 pt、0.5 pt 步进，默认 9 pt，可恢复默认。保存后立即调整主窗口、文件列表、文本预览、上下文菜单和配置对话框，保留当前搜索、选择、预览及历史记录。重启或切换到新数据目录时沿用已保存字号。

字体和布局以原始基线计算，反复调整不会叠加放大；窗口按屏幕范围调整，大字号内容可滚动查看。旧配置无需迁移，缺少字号字段时使用默认值。

本次仅增加本地应用配置 `UiFontSize` 和界面布局逻辑；未涉及业务数据表、业务参数、SQL、DAO、数据字典、查询模板、远程接口或 HEP。

## 0.2.0 — 2026-11-02

### 搜索

- 最近两个文件名索引使用内存 LRU 缓存，文件修改时间或长度变化时失效；更新和删除索引也会同步失效。
- 加载索引与过滤文件名在后台完成，目录导航仅查询索引时间，不反序列化整个索引。
- 全量统计匹配数，只保留最多 5,000 个待展示结果，避免为全部匹配项创建窗口对象。结果统一按目录优先、文件名、仓库和路径排序。
- 状态栏分别显示检索与展示耗时。

基准使用本地索引，不访问远程 SVN；新版本的“首次”表示应用内存缓存为空，未清空操作系统文件缓存。返回上限均为 500，重复值取三次中位数，单位毫秒：

| 数据集 | 原版本解析与筛选 | 新版本首次 | 新版本重复 |
| --- | ---: | ---: | ---: |
| 100,000 条合成目录项 | 746 | 710 | 19 |
| 200,000 条合成目录项 | 1496 | 1448 | 35 |
| 27,357 条本地目录项 | 296 | 321 | 9 |
| 24,849 条本地目录项 | 288 | 243 | 8 |

首次解析仍有成本，首次远程建立索引仍受网络与 SVN 目录扫描耗时影响。上述为索引检索基准，不包含窗口列表绘制时间。

### 历史导航

新增后退、前进按钮及 Alt+Left / Alt+Right。进入搜索结果中的目录后，可直接恢复原搜索结果、关键词、范围、选中行、滚动位置和列宽；历史列表直接从会话内存恢复，不再次发起 SVN 请求。保留最近 30 个视图，后退后访问新位置会清除旧的前进分支。失败或取消的操作不会进入历史。

### 构建与打包

新增 `build.cmd`、`build.sh`、`package.cmd`、`package.sh`；统一调用 PowerShell 构建、验证和生成版本 ZIP。支持带空格和非 ASCII 字符的路径，并保留原进程退出码。`.sh` 支持 Windows Git Bash / Cygwin，以及具备 Windows 互操作的 WSL；不提供原生 Linux/macOS 编译。

打包使用文件允许清单，配置、缓存、索引、日志与本地诊断资料不进入发行包。支持复用已准备的客户端 ZIP，以及不包含客户端的外部 SVN 版本。

验证包含 120 项核心断言和 19 组 Windows 界面测试。界面测试运行于真实消息循环，启用跨线程访问检查，并覆盖搜索历史完整恢复、失败/取消以及前进分支和保留数量限制。
